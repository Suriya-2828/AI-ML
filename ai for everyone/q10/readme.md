# Food Delivery Time Prediction using Machine Learning

## Project Description

This project predicts the delivery time of food orders using Machine Learning. It includes data cleaning, visualization, preprocessing, model training, evaluation, error analysis, and business insights.

## Dataset

Food Delivery Time Prediction Dataset

Features:
- Distance_km
- Weather
- Traffic_Level
- Time_of_Day
- Vehicle_Type
- Preparation_Time_min
- Courier_Experience_yrs

Target:
- Delivery_Time_min

## Technologies Used

- Python 3.11+
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
