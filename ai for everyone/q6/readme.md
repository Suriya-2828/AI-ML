# Spam Email Classification

## Requirements

- Python 3.11+
- pandas
- numpy
- matplotlib
- scikit-learn

## Install Libraries

```bash
pip install -r requirements.txt
```

## Dataset

Place the `SMSSpamCollection` file in the project folder.

## Run the Program

```bash
python spam_classifier.py
```

## Output

- Classification report (displayed in the terminal)
- confusion_matrix.png
