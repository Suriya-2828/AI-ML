# Customer Sales Analysis

## Project Overview

This project performs sales transaction analysis using Python and the Pandas library. It loads a CSV dataset, cleans the data, computes total revenue by product category, identifies the top 10 customers, and visualizes monthly sales trends using Matplotlib.

---

## Requirements

* Python 3.11 or later

### Required Libraries

Install the dependencies using:

```bash
pip install pandas matplotlib
```

## How to Run

Open a terminal in the project directory and execute:

```bash
python customer_sales_analysis.py
```

---

## Output

The program performs the following tasks:

* Loads the sales dataset.
* Cleans missing values.
* Removes duplicate records.
* Converts Order Date to DateTime format.
* Computes revenue by product category.
* Identifies the top 10 customers.
* Generates summary statistics.
* Creates visualizations.

Generated files:

* cleaned_sales_data.csv
* monthly_sales.png
* category_revenue.png
* top10_customers.png
