# Handwritten Digit Recognition using Logistic Regression

## Overview

This project implements a handwritten digit classifier using Logistic Regression and the built-in scikit-learn digits dataset.

---

## Requirements

Python 3.11+

Install required libraries:

```bash
pip install scikit-learn matplotlib
```

---

## Project Files

```text
Question4/
│
├── mnist_digit_classifier.py
├── correct_predictions.png
├── incorrect_predictions.png
├── observations.txt
├── README.md
└── report.pdf
```

---

## How to Run

```bash
python mnist_digit_classifier.py
```

---

## Output

The program generates:

* correct_predictions.png
* incorrect_predictions.png
* observations.txt

The console displays:

* Training Accuracy
* Testing Accuracy

---

## Dataset

Built-in digits dataset from scikit-learn (`load_digits()`).

---

## Machine Learning Algorithm

Logistic Regression
