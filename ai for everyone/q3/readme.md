# Iris Classification using Decision Tree

## Overview

This project trains a Decision Tree classifier on the Iris dataset using scikit-learn. The trained model is evaluated using accuracy, a confusion matrix, and a classification report.

---

## Requirements

Python 3.11+

Install required libraries:

```bash
pip install scikit-learn matplotlib
```
